# MOCK-PROJECTS summary

**10** проектов, **2** на каждого из пяти клиентов `mock_cl_01`…`05`. Полные YAML, сид: `yarn db:seed:mock-projects` (после `yarn db:seed:mock-users`); `DATABASE_URL` — как у других сидов. Ассеты: [public/mock-projects/](public/mock-projects/) (изображения, PDF, DOCX, MP4, M4A), пути в данных — `/mock-projects/...`. Бинарники PDF/DOCX/видео/аудио: `yarn mock-projects:binaries`.

1. `mock_cl_01` — черновик концепт-арта; опубликованный RAG-ассистент
2. `mock_cl_02` — B2B mobile + LLM; video performance (in_progress)
3. `mock_cl_03` — key visuals кампания; отменённый e-commerce ретушь
4. `mock_cl_04` — RAG в регулируемой среде; завершённый ETL
5. `mock_cl_05` — draft in-store Q&A; consulting sprint (prompts)

**19** mock-заявок, вложения — **8** из **10** проектов (**16** записей, **16** файлов). Подробности: [MOCK-PROJECTS.md](MOCK-PROJECTS.md).
