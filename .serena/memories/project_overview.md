# neuro-hub (NeuroGig) - Project Overview

## Purpose

Platform for freelancing in generative AI. Specialized marketplace connecting AI specialists (freelancers) with clients. Features: two-sided marketplace, live demos (Hugging Face Spaces), portfolio, skills verification, project management (Kanban, messenger, time tracking), rating system. Target: 50k DAU, 2k+ transactions/day.

## Tech Stack

- **Frontend**: Next.js 16+, TypeScript 5.9+ (strict), shadcn/ui + Tailwind CSS 4+, lucide-react, Effector 23+
- **Backend**: Node.js 24 LTS, Next.js API Routes, PostgreSQL 16, Knex (migrations/seeds), Kysely (runtime queries), Better Auth 1+
- **Package Manager**: Yarn 4.x via Corepack
- **System**: Darwin (macOS)
