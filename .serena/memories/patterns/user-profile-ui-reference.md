Two screenshots are the approved visual basis for phase-2 profile UI. The target structure is a profile header with avatar on the left, then name + @nickname on the first row, specialization/title on the second row, and a compact meta row with location and spoken languages. The display view is minimal and text-first. The edit view keeps the same overall layout, but adds inline edit affordances: pencil icons near editable text fields, a small camera/edit trigger overlay on the avatar, and action buttons like Share / Preview on the right. Below the header sits a rounded bordered `About` card with generous padding and the bio text. Future `UserProfileEditor` should preserve this structure and visual rhythm rather than switching to a generic stacked form layout. `src/ui/avatar-editor.tsx` should be used as the avatar editing primitive inside that header layout.
