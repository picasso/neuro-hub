Added an account-only Effector store for `/account/*` routes. Server layout `src/app/(account)/layout.tsx` now computes `getAccountContextSnapshot(session)` from `src/lib/account.ts` and passes it into `AccountShell` -> `AccountLayout`, where `AccountContextGate` hydrates `src/stores/account-context/model.ts`. Use this store for account UI role/counters instead of hardcoding sidebar context. The snapshot shape is `{ role, projects?, applications?, works? }`. Counter patch events are exported from the model and already wired into `src/features/projects/create-project-model.ts`, `src/stores/project-applications/model.ts`, and `src/stores/freelancer-portfolio/model.ts` so local mutations can update counts without rehydrating the whole layout.
