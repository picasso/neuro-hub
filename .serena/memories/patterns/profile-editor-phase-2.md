Phase 2 profile UI separates general account profile editing from freelancer-specific editing. `/account/profile` now uses `src/features/profile/*` plus `src/stores/profile/*` for avatar, name, nickname, location, languages, and bio, with inline nickname availability checks through `GET /api/user/profile/nickname`. Freelancer-only specialization/rate/availability/experience stay in `FreelancerProfileEditor` on `/account/skills`, and the account sidebar labels that page `Skills & Experience`. The public freelancer header now reuses the same profile hero basis as the editor, while avatar editing reuses `src/ui/avatar-editor.tsx`.
