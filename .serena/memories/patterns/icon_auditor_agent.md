Added shared project agent `.cursor/agents/icon-auditor.md` for scoped icon cleanup. It is an autofix-oriented agent that only audits the files/folders explicitly named by the user, ignores an extendable exception list that currently starts with `src/ui/shadcn/*`, replaces direct icon usage with `Icon` from `@/ui`, normalizes icon props to `IconName`, may update shared icon infrastructure (`src/ui/assets.tsx`, `src/ui/icon.tsx`, `src/ui/index.ts`, `src/ui/icons/icons.tsx`) when needed, and syncs playground icon catalogs in `src/features/playground/demo-icons-settings.tsx`. When an icon should inherit surrounding text color, the preferred pattern is `color="current"` on `Icon` rather than `className="text-current"`. `.cursor/agents/README.md` includes usage examples.
