Use `PageShell` and `PageContainer` from `src/ui/page-shell.tsx` for route-entry page layout sizing. `PageShell` is the semantic page-level API for single-column route-entry pages and should be used via `preset`, not literal Tailwind width tokens. Current presets are `form | content | wide | full`; internal width caps are mapped to `compact | tablet | desktop | full`, and `spacing` / `inset` remain low-level overrides when needed. `PageContainer` is the low-level primitive for width caps and gutters and should use semantic width tokens (`compact`, `tablet`, `desktop`, `full`) instead of `3xl/4xl/5xl`. `HomePage` uses `PageShell preset="full"`, while full-bleed sections use inner `PageContainer` wrappers. Sidebar-based account or management pages should not be modeled as another `PageShell` preset; they should use a separate structural shell such as `SidebarPageShell` built on top of the same layout foundation.
