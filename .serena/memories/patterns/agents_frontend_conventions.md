Added a specialized agent `.cursor/agents/frontend-advocate.md` for review+refactor of frontend code toward project conventions. Use it when replacing manual UI with existing `@/ui` wrappers (especially `TextField`), migrating legacy `space-x-*` / `space-y-*` layouts to `gap-*` or `Stack`, moving business logic out of `useEffect` / local state into Effector, and normalizing imports through `@/ui`, `@/features`, and `@/features/server`. Also strengthened `.cursor/agents/code-reviewer.md` so reviews now explicitly flag these frontend convention violations in addition to security/performance risks. `.cursor/agents/README.md` documents when to use each agent and how to phrase tasks.
