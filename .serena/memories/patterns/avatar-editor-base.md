`src/ui/avatar-editor.tsx` is now the base reusable avatar editing primitive for the future profile UI. It wraps `FileUploader`, opens a `Dialog`, uses `react-avatar-editor` for circular crop, supports zoom via `Slider`, rotation via `IconButton`, and returns a processed `File` + `Blob` through `onCompleted`. It is exported from `src/ui/index.ts` and already has a playground demo in `src/features/playground/demo-avatar-editor.tsx`, so second-phase profile avatar editing should build on this component rather than creating a new crop/upload UI.
